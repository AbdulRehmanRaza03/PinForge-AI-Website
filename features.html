✦ Smart Scheduling

Posts like a human. Scales like a machine.

The scheduler enforces all safety rules automatically. You set it up once and walk away.

Randomized delays

Every post gets a random 15–60 minute gap after the previous one. Computed freshly each time — no detectable pattern.

Hard daily cap

Maximum 15 pins per Pinterest account per 24-hour rolling window. Enforced server-side — cannot be bypassed.

Background processor

APScheduler runs continuously in the backend. Checks queue every 2 minutes and posts anything that's due — even while you sleep.

Duplicate prevention

SHA-256 hash of title + description blocks identical content from being posted twice to the same account.

Token auto-refresh

Pinterest OAuth tokens expire. PinForge AI automatically refreshes them before posting — no manual re-authentication needed.

Failure handling

If Pinterest returns an error (rate limit, expired token, board not found), the item is marked FAILED with the exact reason logged — never silently dropped.
